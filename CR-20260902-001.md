## 1. Requested Change

### Objective
Freeze the FastAPI OpenAPI contract and the two-person worktree seam so Wave 1 can implement without renaming fields.

### Business or User Value
Hour 0–4 of the 72h contest skeleton: Chiến's API answers `GET /health` with no geospatial credentials; Thanh's Flutter app can hit that API with demo PIN `0000`.

### Scope

**Included**
* Change Request + WT-01 / WT-02 registry
* FastAPI 3.12 scaffold, demo auth, checked-in `apps/api/openapi.json`
* Flutter project under `apps/mobile-driver` with hand-written Dart models

**Excluded**
* Landing visual QA (separate owner; do not edit `apps/landing/**`)
* Next.js `apps/web-portal`
* Paid map / routing / traffic APIs
* OR-Tools, Nominatim wiring, image_picker, solver implementation (later plans)

### Current Behavior
`apps/api` does not exist. `apps/mobile-driver` is a React-PWA README placeholder.

### Expected Behavior
`GET /health` returns `{"status":"ok"}`. Frozen paths appear in `openapi.json`. Flutter PIN screen calls `/health` then `/driver/route`. `GREENLOGIX_DEMO=1` gates Bearer `DEMO` and `X-Driver-Pin: 0000`.
