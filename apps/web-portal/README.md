# GreenLogix Web Portal (Dispatcher Console)

## Overview
Web Portal trung tâm điều hành bưu cục và quản lý đội xe logistics:
- **Quản lý đơn hàng**: Tiếp nhận đơn hàng từ file Excel, Google Sheets, ERP/WMS API.
- **Bản đồ nhiệt & Phân cụm**: Trực quan hóa các điểm giao hàng trên bản đồ số thời gian thực.
- **Kích hoạt tối ưu VRPTW**: Thuật toán gom cụm & phân bổ xe theo tải trọng và Time Windows.
- **Giám sát GPS Live**: Theo dõi vị trí và tiến độ giao hàng của từng tài xế.
- **Báo cáo ESG & CO₂**: Tự động kết xuất báo cáo kiểm kê phát thải chuẩn ISO 14083 / GLEC Framework.

## Tech Stack (Planned)
- Next.js / React 19 + TypeScript
- Tailwind CSS + Shadcn UI
- MapLibre GL / Mapbox GL JS / OpenStreetMap
- TanStack Query + Zustand
