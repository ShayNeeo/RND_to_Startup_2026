# Change Request: `CR-20260907-002`

> Integrator (human or AI): read **§1 then §3** before looking at the diff.

## 1. Outcome

**Objective**: Deploy a 24/7 serverless Cloudflare Workers edge gateway on `greenlogix.w9.nu/*` uniting API, Dispatcher console, Driver PWA, and Landing page under a single origin; implement real OSRM road-network micro-routing with HCMC truck ban compliance; eliminate all emojis in favor of Lucide vector icons; and introduce zero-friction demo role authentication.

**Why now**: To eliminate reliance on local laptop/VPS processes, avoid 4th-level domain wildcard SSL issues (`api.greenlogix.w9.nu`), and provide a polished, judge-ready user experience with instant role access and accurate road-snapped routing.

**Base:** `origin/dev` @ `56260af`

## 2. Scope fence

### MUST KEEP
- Existing landing page sections, styling, pricing calculator, and pilot registration flow.
- Cloudflare D1 persistence (`greenlogix-db`) and OpenAPI endpoints (`/api/orders`, `/api/optimize`, `/api/report`).
- English-only documentation and commit history.
- Zero local machine dependencies (full 24/7 serverless execution).

### MUST CHANGE
- [x] **C-01:** Configure Cloudflare Worker edge router on `greenlogix.w9.nu/*` proxying landing assets from Cloudflare Pages while serving `/api/*`, `/app`, `/dashboard`, and `/driver` natively.
- [x] **C-02:** Integrate OSRM driving geometry pathfinding into dispatcher Leaflet map with client-side caching and fallback.
- [x] **C-03:** Enforce HCMC municipal truck ban (QĐ 23/2018/QĐ-UBND) visual badges on stops in restricted hours (06:00-09:00, 16:00-20:00).
- [x] **C-04:** Replace all emojis across Dispatcher UI and Driver UI with Lucide SVG vector icons.
- [x] **C-05:** Build mobile-first Driver PWA at `/driver` with vehicle selector, stop sequence, and one-tap status writebacks (`arrived`, `delivered`, `failed`).
- [x] **C-06:** Build `RolePortalModal.tsx` on landing page with zero-friction demo auth routing judges and users directly to Quản lý (`/app`) or Tài xế (`/driver`).

### MUST NOT TOUCH
- Contest submissions and financial models in `docs/planning/` and `docs/contest/`.
- Backend optimizer core algorithm contracts (`clustering + NN + 2-opt`).
