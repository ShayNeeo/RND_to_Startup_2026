# Change Request: `CR-20260907-003`

> Integrator (human or AI): read **§1 then §3** before looking at the diff.

## 1. Outcome

**Objective**: Fix the subresource integrity (SRI) hash on `leaflet.js` in `apps/worker/src/dispatcherHtml.ts` which caused browsers to block the script and hang on "Đang kết nối Cloudflare Edge...", pin Lucide CDN versions to prevent redirect latency, and add defensive error boundaries.

**Why now**: User reported the Dispatcher console hung on "Đang kết nối Cloudflare Edge..." with a black map. Browser DevTools confirmed that `leaflet.js` was blocked by Chrome due to an SRI hash mismatch with `leaflet.css` (`p4NxAo...` instead of `20nQCch...`), throwing `ReferenceError: L is not defined` and aborting all subsequent data loading.

**Base:** `origin/dev` @ `b03837e`

- [x] **C-02:** Pin `lucide` CDN URL to `0.475.0` in `dispatcherHtml.ts` and `driverHtml.ts` to eliminate HTTP 302 redirects and latency.
