# Contributing

Process lives in [`rules/README.md`](rules/README.md). Short version:

1. Branch from `dev`.
2. Multi-person or multi-agent work: file `changes/CR-YYYYMMDD-NNN.md` from [`rules/forms/CHANGE_REQUEST.md`](rules/forms/CHANGE_REQUEST.md). Fill **MUST KEEP / MUST CHANGE / MUST NOT TOUCH** before coding.
3. PR into `dev` (template `feature-to-dev`).
4. QA on `dev`, then PR `dev` → `stable` (template `promote-to-stable`).

Agents: start at [`AGENTS.md`](AGENTS.md).
